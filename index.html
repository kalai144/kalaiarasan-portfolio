Projects

Surface Defect Detection on Weldments using ANFIS

This project focused on improving the efficiency of weld defect inspection in manufacturing industries. Traditional inspection methods are time consuming and may lead to inconsistent results.

An Adaptive Neuro Fuzzy Inference System (ANFIS) model was developed to analyze weld surface characteristics and detect defects automatically. The system improves inspection accuracy and reduces inspection time significantly.

Technologies Used: Python, AI Algorithms, Data Analysis

RADAR Sensing Detection using Arduino

This project involved developing a radar detection system using Arduino and ultrasonic sensors to detect nearby objects and obstacles.

The radar system scans its surroundings and displays object detection results in real time. The prototype was demonstrated at a college technology exhibition and received **2nd place** recognition.

Technologies Used: Arduino, Embedded Systems, Sensor Programming

Personal Health Guardian

Personal Health Guardian is an AI-based healthcare analysis system developed using Python.

The system reads medical PDF reports and extracts key health indicators such as blood parameters and diagnostic results.

It then generates insights including health summaries, risk indicators, lifestyle recommendations and trend analysis to help users better understand their medical conditions.

Technologies Used: Python, Data Processing, AI Analysis
